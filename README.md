# Password Validator

A simple password validation app built with HTML, CSS, and JavaScript.

## Features
- Checks password length
- Validates uppercase and lowercase letters
- Checks for numbers and special characters
- Provides instant feedback to the user

## Tech Stack
- HTML
- CSS
- JavaScript

## Run Locally
1. Clone the repository
2. Open `index.html` in your browser

## Description
This project helps users create strong and secure passwords by validating common password requirements. It is a useful practice project for learning JavaScript form validation.
